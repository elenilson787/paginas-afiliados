# Shopee Affiliate SaaS

SaaS em Next.js + Supabase Auth para afiliados Shopee.

## Stack
- Next.js
- TypeScript
- Supabase Auth
- Supabase Postgres
- Tailwind CSS

## Setup
1. Crie um projeto no Supabase.
2. Copie URL e chave pública para `.env.local`.
3. Instale dependências.
4. Rode `npm run dev`.

## Rotas
- `/login`
- `/signup`
- `/dashboard`
- `/auth/callback`
